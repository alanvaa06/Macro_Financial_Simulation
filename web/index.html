Model

  • Y = K^α · (A·L)^(1-α)  — Cobb-Douglas production
  • K_{t+1} = (1 − δ)·K_t + s·Y_t  — capital accumulation (textbook)
  • g_real = (1+n)(1+g) − 1  — steady-state growth (closed form; the simulation is a convergence check)
  • R_f = g_real + π + TP  — Fisher + term premium
  • k_e = R_f + β · ERP  — CAPM
  • P/E = (1 − b) / (k_e − g_e)  — Gordon Growth (single stage), or two-stage with terminal growth = nominal GDP
  • D = −(∂P/E ∕ ∂k_e) ∕ (P/E)  — P/E duration (years); = 1 / (k_e − g_e) single stage

Educational tool — not investment advice. Steady-state Y/K = ((1+n)(1+g) − (1−δ)) / s.
